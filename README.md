# Answer Checker

I often got annoyed seeing the correct answers accidentally while doing tests. Once I saw them, I couldn’t unsee them — my brain started matching instead of thinking. So I created a simple tool that only tells whether your answer is correct or wrong, without revealing the right one.

The idea came from personal need, and the code was fully AI-generated. Even though it’s small and looks like a prototype, it works perfectly for my use. I didn’t search for existing tools — I just wanted something that fit my own workflow. Now I have it, and I’m sharing it in case someone else faces the same issue.
